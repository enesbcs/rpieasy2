# AGENTS.md

## Project: Python3 Workspace

This file defines how AI agents should behave when working in this repository.

---

## 1. General Behavior
- Prefer simplicity and readability over clever solutions.
- Follow PEP 8 style guidelines for Python code.
- Keep changes minimal and focused on the user’s request.
- Do not modify unrelated files.

---

## 2. Code Standards
- Use Python 3.x compatible syntax only.
- Use type hints where practical.
- Avoid unnecessary dependencies.
- Prefer standard library solutions when possible.

---

## 3. Project Structure Awareness
- Respect existing folder structure.
- Place new modules only where they logically belong.
- Do not create duplicate utilities.

---

## 4. Testing
- Ensure code is testable and deterministic.
- If tests exist, update them accordingly.
- Do not remove tests unless explicitly instructed.

---

## 5. File Handling
- Be cautious with file operations.
- Never overwrite user data without explicit instruction.

---

## 6. Performance
- Prefer clean and readable code over premature optimization.
- Optimize only when necessary or requested.

---

## 7. Security
- Never introduce insecure patterns (e.g., eval, unsafe deserialization).
- Do not expose secrets or hardcode credentials.

---

## 8. Communication Style (for agents)
- Be concise and technical.
- Avoid unnecessary explanations unless requested.

---

## 9. Ignore Policy Note
- Follow `.gitignore` for excluding files.
- If an `.opencodeignore` or similar file exists, it takes precedence for agent indexing rules.

---

End of AGENTS.md
